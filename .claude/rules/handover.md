# 引き継ぎメモ

- 作業の進捗は `handover.local.md` に記録する。gitignore 対象のローカルファイルなのでリポジトリからは辿れない。なければ作る。
- 更新するのは、方針を決めたとき・タスクを完了したとき・環境の注意点が判明したとき・保留が解けたときの 4 つ。都度の作業ログではなく「次のセッションが知る必要のある状態」を書く。
- `docs/plan.md` と重複させない。`docs/plan.md` はタスクの一覧、`handover.local.md` は現在の状態と決定事項。
- `CLAUDE.md` や `docs/design/` に書けるものは、そちらに書いて `handover.local.md` からは消す。`handover.local.md` は gitignore 対象で、他の環境にも他の contributor にも届かない。
- **保留を書いたら、解けたときに消す。** 「〜に据え置き」「〜のマージを待つ」の類は、その状態が解けたときに誰も直さない。#66 の整理では「`reqwest` だけ 0.12 に据え置き」（#59 で上げ済み）と「#63 のマージを待つ」（マージ済み）が逆を向いたまま残っていた。上の引き金に「保留が解けたとき」が入っているのはこのため。
- **PR ごとに 1 行増えるリストは、教訓の類型ごとに畳む。** PR 番号は根拠として残す。畳まないと PR のたびに線形に伸びて読まれなくなる。新しい類型が出たときだけ項目が増える形にする。
